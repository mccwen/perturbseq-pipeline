# Glossary

- **Perturb-seq / CROP-seq**: single-cell RNA-seq coupled with pooled genetic perturbations.
- **Guide assignment**: mapping each cell to the most likely CRISPR guide using guide capture reads.
- **Non-targeting control**: guide with no intended genomic target, used as a negative control.
- **Escaped perturbation**: guide-positive cell without the expected target perturbation signature.
- **Pseudobulk**: aggregate expression counts across cells within replicate-aware groups.
- **Design matrix**: sample-level metadata used by a statistical model for differential expression.
- **Batch correction**: computational removal of unwanted variation, usually safer for visualization than inference.
